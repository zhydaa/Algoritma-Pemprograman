#Fungsi / Function 
- blok kode yang terstruktur 
- untuk melakukan tugas tertentu
- bisa di panggil beberapa kali

#Keuntungan fungsi
1. Mengurangi kode yang berulang
2. program lebih terstruktur
3. kode lebih mudah dibaca
4. kode lebih mudah dipartisipasi 
5. Function dapat digunakan berkali-kali
6. program besar dapat di bagi menjadi beberapa bagian kecil

#Struktur fungsi
def: keyword untuk membuat Function
fungsi: nama Function
(): tempat parameter
: awal blok kode
